AIFusion — AI Copilot

AI copilot for Autodesk Fusion 360. This add-in adds a docked chat palette to Fusion that drives your design natively — sketching, modelling, editing features, verifying results through viewport screenshots — through normal conversation with the AI provider of your choice.

Features

  • Docked chat palette inside Fusion (no browser tab)
  • 6 AI providers with latest flagship models (2026-08): DeepSeek · Kimi · Zhipu GLM · OpenAI · Claude · Gemini
  • Agentic tool loop — the model reads model state (read), builds via Python scripts (execute), up to 10 rounds per request
  • Visual verification loop — captures the Fusion viewport and lets vision-capable models sanity-check the design (up to 3 repair rounds; screenshots auto-downscaled)
  • Attachments — images / PDFs (≤8 MB each, max 4) as design reference, auto-downscaled in the browser
  • Project history — conversations persist to a local SQLite database; restore any session after a restart
  • Capability-aware gating: text-only models (DeepSeek official API, GLM-5.3) degrade gracefully instead of failing
  • Auto-dependency install; model aliases (sonnet5, fable, gpt5.6, gemini-3.7); low sampling temperature (0.2) for reproducible scripts; collapsible tool-call log cards

What gets sent over the network

Your prompts, tool calls & results, and any reference images you attach are sent to the model provider you selected (and keyed). The add-in does not upload your .f3d / .f3z files — all Fusion API work happens in-process inside Fusion via adsk.fusionSendData; only the chat protocol leaves your machine, from 127.0.0.1 (default port 8765, auto-fallback 8765–8780) to your provider's API.

Install

Option A — one-click: double-click install.bat; it copies the add-in into Fusion's AddIns folder, installs flask + requests, and runs a guided API-key setup.

Option B — manual: clone the repository into Fusion's add-in folder:

git clone https://github.com/zhou19830318/AIFusion.git "%APPDATA%\Autodesk\Autodesk Fusion 360\API\AddIns\AIFusion"

Or download the ZIP from GitHub and extract to %APPDATA%\Autodesk\Autodesk Fusion 360\API\AddIns\AIFusion\. Dependencies (flask, requests) are auto-installed on first launch; you can install them upfront by running install_deps.bat as Administrator.

Configure API key

Edit local_server\config.json (local file, git-ignored) and set at least one provider key, e.g.:

{
  "provider": "deepseek",
  "model": "deepseek-v4-pro",
  "deepseek_api_key": "sk-your-deepseek-key-here"
}

Full key set: deepseek / kimi / zhipu / openai / anthropic / google_api_key (each provider also has a <provider>_base_url override). Use local_server/config.example.json as the key-less template. Keys are obtained from each provider's platform (DeepSeek, open.bigmodel.cn, platform.openai.com, console.anthropic.com, aistudio.google.com, platform.moonshot.cn). Provider keys are also read from environment variables (e.g. DEEPSEEK_API_KEY) as a fallback.

Enable in Fusion 360

After install, fully quit Fusion and reopen it. In Fusion press Shift+S → Add-Ins tab → find AIFusion → click Run and tick Run on Startup. The chat palette docks on the right side; open Settings via the ⚙ badge to pick a provider/model and enter an API key. A toolbar button on the Solid tab reopens the palette any time.

Security notes

  • local_server/config.json (API keys) is excluded from version control — never push it to a public repository; keys are masked in every API response.
  • Fusion files are never uploaded; only conversation text, tool results and your attached reference images leave the machine.
  • The local API accepts loopback browser origins only and rejects attacker-controlled base_url values; the history database never stores keys or raw image data.

Uninstall

Quit Fusion, then delete the folder:

%APPDATA%\Autodesk\Autodesk Fusion 360\API\AddIns\AIFusion

…and restart Fusion.
