Fusion360-Add-Ins — AI Copilot

AI copilot for Autodesk Fusion 360. This add-in adds a docked chat palette to Fusion that drives your design natively — sketching, modelling, editing features, verifying results through viewport screenshots — through normal conversation with the AI provider of your choice.

Features

  • Docked chat palette inside Fusion (no browser tab)
  • 6 AI providers with latest flagship models (2026-08): DeepSeek · Kimi · Zhipu GLM · OpenAI · Claude · Gemini
  • Visual verification loop — captures the Fusion viewport and lets vision-capable models sanity-check the design (up to 3 repair rounds)
  • Attachments — images / PDFs (≤8 MB each, max 4) as design reference
  • Capability-aware gating: text-only models (DeepSeek official API, GLM-5.3) degrade gracefully instead of failing
  • Auto-dependency install; model aliases (sonnet5, fable, gpt5.6, gemini-3.7); progress feedback with elapsed-time counter

What gets sent over the network

Your prompts, tool calls & results, and any reference images you attach are sent to the model provider you selected (and keyed). The add-in does not upload your .f3d / .f3z files — all Fusion API work happens in-process inside Fusion via adsk.fusionSendData; only the chat protocol leaves your machine, to localhost:8765 → your provider's API.

Install

Clone the repository into Fusion's add-in folder:

git clone https://github.com/zhou19830318/Fusion360-Add-Ins.git "%APPDATA%\Autodesk\Autodesk Fusion 360\API\AddIns\Fusion360-Add-Ins"

Or download the ZIP from GitHub and extract to %APPDATA%\Autodesk\Autodesk Fusion 360\API\AddIns\Fusion360-Add-Ins\.

Dependencies (flask, requests) are auto-installed on first launch; you can install them upfront by running install_deps.bat as Administrator.

Configure API key

Edit local_server\config.json (local file, git-ignored) and set at least one provider key, e.g.:

{
  "provider": "deepseek",
  "model": "deepseek-v4-pro",
  "deepseek_api_key": "sk-your-deepseek-key-here",
  "openai_api_key": "",
  "anthropic_api_key": "",
  "google_api_key": ""
}

Use local_server/config.example.json as the key-less template. Keys are obtained from each provider's platform (DeepSeek, open.bigmodel.cn, platform.openai.com, console.anthropic.com, aistudio.google.com, platform.moonshot.cn).

Enable in Fusion 360

After install, fully quit Fusion and reopen it. In Fusion press Shift+S → Add-Ins tab → find Fusion360-Add-Ins → click Run and tick Run on Startup. The chat palette docks on the right side; open Settings via the ⚙ badge to pick a provider/model and enter an API key.

Security notes

  • local_server/config.json (API keys) is excluded from version control — never push it to a public repository.
  • Fusion files are never uploaded; only conversation text, tool results and your attached reference images leave the machine.

Uninstall

Quit Fusion, then delete the folder:

%APPDATA%\Autodesk\Autodesk Fusion 360\API\AddIns\Fusion360-Add-Ins

…and restart Fusion.
